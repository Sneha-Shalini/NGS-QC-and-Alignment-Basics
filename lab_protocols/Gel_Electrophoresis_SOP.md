# Agarose Gel Electrophoresis SOP

**Purpose:** Visualize and check DNA / PCR product size

**Materials:** Agarose, 1X TAE Buffer, Ethidium Bromide / SYBR Safe, Loading Dye, DNA Ladder

**Steps:**
1. Weigh 1g Agarose for 1% gel + 100ml 1X TAE
2. Microwave to dissolve, cool slightly
3. Add 3ul EtBr/SYBR Safe, pour into casting tray with comb
4. Let solidify (20-30 min)
5. Load: 5ul sample + 1ul loading dye, plus 5ul ladder
6. Run at 80-100V for 45-60 min
7. Visualize under UV Transilluminator

**Safety:** EtBr is mutagenic - wear gloves, UV protection.
